# v1.5.9

## 改进（部署）

- **支持 fork / 私有仓库部署**：在线更新此前把上游仓库写死在两处，部署到自己的 fork 时无法维护。现在一键安装脚本的仓库地址可用环境变量覆盖（`GITHUB_REPO`），OTA 回退到源码构建时校验的 Git origin 也可由运维显式声明（`INCUDAL_TRUSTED_GIT_ORIGIN`）；未设置任何环境变量时行为与旧版完全一致，仍指向上游仓库。

  部署到 fork 的用法：

  ```bash
  GITHUB_REPO=<你的组织>/payincus \
  INCUDAL_TRUSTED_GIT_ORIGIN=https://github.com/<你的组织>/payincus.git \
  sudo bash install-panel.sh
  ```

- **版本同步**：根、客户端、服务端三处 `package.json` 统一为 1.5.9。Service Worker 缓存名已从注册参数推导，无需手工 bump。

> 本版不涉及数据库结构变更。基于 v1.5.8。
